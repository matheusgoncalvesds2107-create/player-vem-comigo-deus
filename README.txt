PLAYER WEB RÁDIO VEM COMIGO DEUS — RENDER

OBJETIVO:
URL pública apenas do player, separada do painel.

COMO PUBLICAR NO RENDER:
1. Crie um repositório GitHub, por exemplo: player-vem-comigo-deus
2. Envie index.html deste pacote.
3. Render > New + > Static Site
4. Conecte o repositório.
5. Branch: main
6. Build Command: vazio
7. Publish Directory: .
8. Create Static Site

IMPORTANTE:
O player usa o sinal atual do Caster por trás da interface.
Nenhuma página do Caster é aberta.
Se o token do stream expirar, será necessário atualizar a URL do sinal no index.html.
